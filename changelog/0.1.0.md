# [0.1.0] — 2026-05-27

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## Добавлено

- **Ядро.** Оркестратор **`DefaultDocumentEngine`** и plain-Java входная точка **`DocumentEngineBuilder`**: рендер шаблона выбранным движком, при необходимости конвертация в целевой формат, результат — имя файла, MIME-тип и байты (`generate()`).
- **Модель API.** `GenerationRequest` / `GenerationResult` / `GenerationOptions`, ссылки на шаблон **`TemplateReference.BytesRef`** / **`InputStreamRef`**, форматы `DocumentFormat.XLSX` / `PDF`.
- **Модель ошибок.** Единая unchecked-иерархия **`DocumentGenerationException`** (`templateHint`, source/target-форматы в каждом исключении); внутренние ошибки JXLS/POI/I-O наружу не утекают, содержимое шаблона и данные в сообщения не попадают.
- **SPI.** `TemplateEngine`, `DocumentConverter`, `TemplateResolver`, `TemplateValidator`, `TempFileManager` и контексты рендера/конвертации; выбор реализации — registry pattern по первому `supports(...)`.
- **JXLS.** **`JxlsTemplateEngine`**: рендер XLSX-шаблонов с полями `${...}`, циклами `jx:each` (стили и границы строк сохраняются) и формулами — пересчёт делегирован открывающему приложению (`setForceFormulaRecalculation(true)`).
- **PDF.** **`LibreOfficeConverter`**: headless `soffice --convert-to pdf` с изолированным профилем `UserInstallation` на каждый вызов, таймаутом, чтением stderr и уборкой временного каталога.
- **Temp-файлы.** **`DefaultTempFileManager`**: трекинг созданных файлов, удаление при `close()` и через shutdown-hook.
- **Spring Boot.** Стартер с авто-конфигурацией `DocumentEngine` для Spring Boot 2.7 и свойствами `doc-engine.*`.
- **Сборка и публикация.** Многомодульный Maven-реактор (`doc-engine-core`, `doc-engine-spring-boot-starter`), лицензия Apache-2.0, CI-сборка на push/PR и релиз в GitHub Packages по тегу `v*` с sources- и javadoc-джарами.
